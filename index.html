Interactive drawing surface. Choose a tool from the panel on the left, then click the canvas to draw, or use the keyboard: arrow keys move a keyboard cursor in grid steps, Enter performs the active tool's action at the cursor, Escape cancels an in-progress bond or arrow, Delete removes the selected item. Keyboard shortcuts & help

V select  A atom  B bond  T text  E erase  R arrow

C N O S P F H switch to the Atom tool with that element from anywhere — or, if you have an atom selected with the Select tool, relabel it instantly instead.

Ctrl/Cmd+Z undo  Ctrl/Cmd+Shift+Z redo

Delete remove selection  Arrows nudge selection or move keyboard cursor

Enter perform active tool at keyboard cursor  Esc cancel

Click an existing bond with the Bond tool to cycle single → double → triple → wedge → hash.

Mouse wheel zooms toward the pointer. Hold Space and drag, or drag with the middle mouse button, to pan.

The Atom, Bond, and Erase tools stay active so you can place, chain, or clear several things in a row; Text and the reaction arrows switch back to Select after one, since you'll usually want to type or edit right away.

Templates and pasted SMILES both insert at the keyboard cursor's position, then hand control to the Select tool so you can drag the result into place.
